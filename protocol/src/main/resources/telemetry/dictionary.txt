# Telemetry dictionary for the two-stage vehicle.
#
# "packet <apid> <name> <rate_hz> <description>" opens a packet. The rows under it are
# its channels in wire order, big-endian, after the 12-byte CCSDS header. A rate of 0
# means the packet is sent when something happens rather than on a schedule.
#
# class    sensor  = a transducer reading, watched for flatlining
#          derived = computed by the flight computer
#          status  = a discrete state
# limits   red_lo yel_lo yel_hi red_hi
# rate     largest normal |d/dt|, in units per second
# when     the limit, rate and flatline checks run only while this holds:
#          CHANNEL means non-zero, CHANNEL=value means equal
#
# A dash leaves a field unset.
